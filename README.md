# Фармакология — тренажёр пересдачи

Статический учебный тренажёр: 520 тестов по 130 темам, 45 экзаменационных билетов, классификации с примерами МНН и 282 задания по рецептуре.

- Бесконечная практика: теория с классификациями и отдельно рецепты.
- Последовательный или случайный порядок, повторение ошибок.
- Прогресс сохраняется только в браузере; есть экспорт и импорт.
- Адаптивная вёрстка для телефона и компьютера.

## GitHub Pages

Публикация из ветки `main`, каталог `/`. Сборка и зависимости не требуются. Файл `.nojekyll` отключает обработку Jekyll.

## Проверка содержания

Учебные материалы проверены выборочно. Источники, точечные правки и ограничения указаны в разделе «Правки и источники». Дозировки в рецептуре являются условиями учебных заданий и не предназначены для самостоятельного лечения.

## Обновление

После изменения файлов в `main` GitHub Pages публикует обновление автоматически. Пользовательский прогресс в репозиторий не передаётся.
